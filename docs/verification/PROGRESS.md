## Review and hardened build
A fresh read-only review found three material import issues: deterministic conflict IDs could discard an incoming version after editing its earlier copy; compressed image limits did not bound decoded dimensions; folder IDs could collide with virtual collections. Added regressions and observed all three fail, then fixed collision resolution (checking each destination's content), bounded PNG/JPEG/WebP dimensions before import plus sampled bitmap display, and remapped reserved folder IDs/references. All 15 unit tests, lint (zero errors), debug APK and instrumentation APK build now pass. The original clean PNG icon was empty; replaced it with an adaptive vector based on the existing eight-ray Aster mark, including monochrome variant. Font weights were instantiated into static OFL fonts for Android 26+ compatibility. ARM64 native libraries have 0x4000 ELF segment alignment (16 KiB).
